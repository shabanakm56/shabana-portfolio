# shabana-portfolio

Personal portfolio for Shabana: web development and data analytics projects, skills, education and contact details.

## Stack
Next.js 14 (App Router), Tailwind CSS 3, React 18. No API keys or environment variables.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Customize
All text lives in `data/content.js` (profile, projects, skills, education, certifications). Colors (light and dark) are in `app/globals.css`.

## Deploy
Push to GitHub, import the repo in Vercel, keep the default Next.js settings, and deploy.
